## 关于本站

这是 Just Tu 使用 **Jekyll + GitHub Pages + GitHub Actions** 搭建的个人技术博客，
专注于 AI、云原生与工程效率方面的实践记录。

## 为什么写博客

- **整理知识**：写下来的东西才算真正理解；
- **长期积累**：静态站点的文章就是纯文本，十年后依然可以无损迁移；
- **开放分享**：把踩过的坑沉淀下来，帮后来人节省时间。

## 本站架构

```text
Markdown 文章 → Git push → GitHub Actions 自动构建 → GitHub Pages 发布
```

写一篇文章的全部流程只有三步：新建 Markdown 文件、commit、push，
其余全部自动完成。
